# Set a mandate

> **Status: planned.** This page is written on Day 2. The outline below shows what it will cover.

A mandate is a standing "yes" with hard limits, so routine actions run without a click each time.

## What this page will cover

- Create one: tool, per-call cap, budget, payees, max uses, expiry.
- What happens at the limit (it asks a human).
- Revoke a mandate.
